# Ameer

I used to run bits of a bank. Now I make things on the internet.

I spent ten years in Bank of America Fixed Income, eventually as COO for
four trading businesses. Then came fintech, startups and, somewhat
unexpectedly, writing software myself.

I tend to make things for one of two reasons: something keeps annoying me,
or I cannot stop wondering whether it could exist.
